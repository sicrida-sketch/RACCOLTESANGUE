☁️ Sincronizzazione Dati Condivisi

Abilita la sincronizzazione per condividere i dati con tutti gli utenti

📖 Come configurare (clicca per espandere)

Per abilitare la condivisione dati tra tutti gli utenti:

  1. Crea un progetto Firebase gratuito su console.firebase.google.com
  2. Vai in "Realtime Database" e crea un database
  3. Nelle regole del database, usa queste impostazioni: 
    {
  "rules": {
    "punti": {
      ".read": true,
      ".write": true
    }
  }
}
  4. Vai in "Impostazioni Progetto" → "Le tue app"
  5. Copia la configurazione Firebase
  6. Modifica il file app.js e sostituisci firebaseConfig con i tuoi valori
  7. Ricarica l'app e abilita la sincronizzazione

⚠️ Nota: Una volta configurato, tutti i dati saranno condivisi tra tutti gli utenti che accedono all'app!

# 📖 Guida alla Configurazione di GitHub Pages

Questa guida ti aiuterà ad attivare GitHub Pages per rendere l'app accessibile online.

## ✅ Verifica se GitHub Pages è già attivo

1. Vai su: https://github.com/sicrida-sketch/RACCOLTESANGUE
2. Clicca su **Settings** (Impostazioni)
3. Nel menu laterale, clicca su **Pages**
4. Se vedi un link verde con l'URL dell'app, è già attivo! ✨

## 🚀 Attivare GitHub Pages (se non è già attivo)

### Passo 1: Accedi alle Impostazioni
1. Vai alla pagina del repository: https://github.com/sicrida-sketch/RACCOLTESANGUE
2. Clicca sulla scheda **Settings** (in alto a destra)

### Passo 2: Configura Pages
1. Nel menu laterale sinistro, scorri verso il basso
2. Clicca su **Pages** (sotto la sezione "Code and automation")

### Passo 3: Seleziona la Sorgente
1. Nella sezione **"Source"** (Sorgente):
   - Clicca sul menu a tendina
   - Seleziona il branch **main** (o **master** se non vedi main)
   - Lascia la cartella su **/ (root)**
2. Clicca sul pulsante **Save** (Salva)

### Passo 4: Attendi il Deployment
1. GitHub mostrerà un messaggio che dice che il sito è in costruzione
2. Attendi 1-2 minuti
3. Ricarica la pagina
4. Dovresti vedere un banner verde con il tuo URL:
   ```
   https://sicrida-sketch.github.io/RACCOLTESANGUE/
   ```

## ⚠️ Nota Importante

- Ogni volta che fai modifiche ai file e le carichi su GitHub, l'app si aggiornerà automaticamente
- L'aggiornamento può richiedere 1-2 minuti
- Se fai modifiche, avvisa gli utenti di ricaricare la pagina (F5 o pull down su mobile)

## 🔒 Sicurezza

- L'app è protetta da PIN (predefinito: 000000)
- I dati sono salvati localmente nel browser di ogni utente
- GitHub Pages usa automaticamente HTTPS per la sicurezza

## 🆘 Problemi?

Se l'app non si carica:
1. Verifica che GitHub Pages sia attivo (vedi sopra)
2. Controlla che il link sia esattamente: `https://sicrida-sketch.github.io/RACCOLTESANGUE/`
3. Prova a cancellare la cache del browser o usare una finestra in incognito
4. Attendi qualche minuto se hai appena attivato GitHub Pages

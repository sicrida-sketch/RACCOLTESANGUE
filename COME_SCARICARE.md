# 📥 Come Scaricare i File Modificati

## 🎯 Dove Trovare e Scaricare i File

I file modificati dell'applicazione RACCOLTESANGUE sono disponibili sul repository GitHub. Ci sono **diversi modi** per scaricarli:

---

## 🌐 Metodo 1: Usare Direttamente l'App Online (CONSIGLIATO) ⭐

**Non serve scaricare nulla!** L'app funziona direttamente online:

### 👉 Apri questo link:
**https://sicrida-sketch.github.io/RACCOLTESANGUE/**

✅ **Vantaggi:**
- Sempre aggiornata automaticamente
- Nessun download necessario
- Funziona su telefono, tablet e computer
- Puoi salvarla sulla schermata principale del telefono

### 📱 Come Salvare sul Telefono (Senza Scaricare):

**iPhone/iPad:**
1. Apri il link in Safari
2. Tocca il pulsante "Condividi" (quadrato con freccia)
3. Scorri e tocca "Aggiungi a Home"
4. Conferma - l'app apparirà come icona sulla schermata principale!

**Android:**
1. Apri il link in Chrome
2. Tocca il menu (tre puntini verticali)
3. Seleziona "Aggiungi a schermata Home"
4. Conferma - l'app apparirà sulla schermata principale!

## 💾 Metodo 2: Scaricare Tutto il Repository come ZIP

Se vuoi scaricare tutti i file per usarli offline sul tuo computer:

### Passi da Seguire:

1. **Vai alla pagina del repository:**
   ```
   https://github.com/sicrida-sketch/RACCOLTESANGUE
   ```

2. **Clicca sul pulsante verde "Code"** (in alto a destra)

3. **Seleziona "Download ZIP"**

4. **Salva il file ZIP** sul tuo computer

5. **Estrai il file ZIP** 
   - Su Windows: Fai clic destro → "Estrai tutto"
   - Su Mac: Doppio clic sul file ZIP

6. **Apri il file `index.html`** con il browser
   - Doppio clic su `index.html`
   - Oppure: Fai clic destro → Apri con → Browser (Chrome, Firefox, Safari, ecc.)

### ✅ Cosa Ottieni:
- Tutti i file dell'app
- Possibilità di usare l'app offline
- Tutti i file di documentazione

---

## 🔧 Metodo 3: Scaricare Solo i File Necessari

Se vuoi scaricare solo i file essenziali per far funzionare l'app:

### File Necessari (3 file):

1. **`index.html`** - La pagina principale
2. **`app.js`** - Il codice JavaScript
3. **`styles.css`** - Gli stili

### Come Scaricarli:

1. Vai su: https://github.com/sicrida-sketch/RACCOLTESANGUE

2. Clicca su ogni file (uno alla volta)

3. Clicca sul pulsante **"Raw"** (in alto a destra)

4. Salva la pagina:
   - **Windows/Linux:** Ctrl+S
   - **Mac:** Cmd+S

5. Salva tutti e 3 i file nella **stessa cartella**

6. Apri `index.html` con il browser

---

## 💻 Metodo 4: Clonare il Repository (Per Utenti Avanzati)

Se conosci Git e vuoi tenere i file sempre aggiornati:

### Requisiti:
- Git installato sul computer
- Conoscenza base dei comandi Git

### Comandi:

```bash
# Clona il repository
git clone https://github.com/sicrida-sketch/RACCOLTESANGUE.git

# Entra nella cartella
cd RACCOLTESANGUE

# Apri index.html con il browser
```

### Per Aggiornare in Futuro:
```bash
# Entra nella cartella del repository
cd RACCOLTESANGUE

# Scarica gli aggiornamenti
git pull
```

## 🆘 Risoluzione Problemi

### L'app non si apre dopo il download
- ✅ Verifica di aprire `index.html` (non altri file)
- ✅ Assicurati che tutti e 3 i file siano nella stessa cartella
- ✅ Usa un browser moderno (Chrome, Firefox, Safari, Edge)

### I dati non si salvano
- ✅ Controlla che JavaScript sia abilitato nel browser
- ✅ Alcuni browser bloccano localStorage in modalità file://
- ✅ Soluzione: usa l'app online (Metodo 1)

### Non riesco a scaricare i file
- ✅ Controlla la connessione internet
- ✅ Prova con un browser diverso
- ✅ Usa il Metodo 2 (ZIP) se il Metodo 3 non funziona
